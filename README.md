# RocketCoffee

This project is from my earlier HTML and CSS studies with Rocketseat. It's a course exercise, kept here as part of my learning history.

A learning project built during Rocketseat's Explorer Marathon 3.0 to practice a digital coffee shop menu with HTML and CSS.

The exercise focuses on a static menu layout that can be shared through a link or QR code. It does not implement ordering or payments.

## Skills practiced

- Semantic HTML
- CSS styling and Flexbox
- Organizing menu sections and item descriptions

## View the project

[GitHub Pages demo](https://nicolasoliveiraops.github.io/projeto-rocket.coffee/)

## Run locally

Clone or download this repository and open `index.html` in a browser. No build step is required.
